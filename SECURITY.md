# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Reconpipeline (ThreatLens)**, please report it responsibly via GitHub Security Advisories on [https://github.com/khaleddevsec/Reconpipeline](https://github.com/khaleddevsec/Reconpipeline) rather than opening a public issue.

## Responsible Use

Reconpipeline is designed for authorized security assessments, DevSecOps pipelines, and defensive posture evaluation. Always obtain explicit permission before scanning targets you do not own.
